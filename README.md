# AI Projects Portfolio

A portfolio of AI projects, built in the open by a beginner who learns by building.
It starts with projects **made with AI** and moves towards **AI-powered** projects.

Every project here follows three promises:

1. **Verified claims.** Every number traces to a documented source.
2. **Trusted sources.** Only official or primary data, recorded in `sources.md`.
3. **Honest process.** Each project keeps a dated dev log, mistakes included.

## How the work is done

Each project runs the same cycle: **plan → build → verify → log → publish**.
Tasks live on the [project board](https://github.com/users/olucasbernardino/projects/3). Changes arrive as pull
requests and are checked against the [verification checklist](docs/verification-checklist.md).

## AI use

AI assistants help build these projects under written rules:
[`AGENTS.md`](AGENTS.md) and [AI roles](docs/ai-roles.md). Every change says
which AI did what.
