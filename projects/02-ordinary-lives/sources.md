# Sources: Ordinary Lives (sandbox)

**There are no real sources in this sandbox.** Every number is invented by
`scripts/generate-fake-data.mjs`, and every "source release" in
`data/source_releases.json` is a made-up name (for example "Imaginary Vital
Statistics Office"), so nothing can be mistaken for fact.

When real data is wired in, each real dataset gets a row below, and the fake files
are replaced.
